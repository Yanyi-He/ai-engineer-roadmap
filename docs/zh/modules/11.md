## 按需参考

- [Hamel Husain: Your AI Product Needs Evals](https://hamel.dev/blog/posts/evals/) — 从错误分析出发的评测方法：读 trace、分层测试与数据飞轮。
- [Hamel Husain: Using LLM-as-a-Judge for Evaluation](https://hamel.dev/blog/posts/llm-judge/) — 让 judge 与领域专家对齐：二元判断、带理由的标注与一致率迭代。
- [Inspect AI](https://inspect.aisi.org.uk/) — 开源评估框架；学 dataset、solver、scorer 和 sandbox。
- [Ragas Documentation](https://docs.ragas.io/en/stable/) — 拆开 retrieval、faithfulness 与 answer quality；judge 不能代替人工标注。
- [Adding Error Bars to Evals](https://arxiv.org/abs/2411.00640) — Anthropic 的评测统计论文：标准误、聚类题目、配对差异与功效分析，直接对应模型/系统对比。
- [SciPy: Bootstrap](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html) — 选读重采样假设、配对与退化情形。
- [OpenTelemetry GenAI Semantic Conventions](https://opentelemetry.io/docs/specs/semconv/gen-ai/) — 统一 spans/usage/模型信息；字段成熟度需跟规范版本核对。
- [Langfuse Self Hosting](https://langfuse.com/self-hosting) — 本地 trace、数据集与实验，不把全部敏感 prompt 发到第三方。
- [promptfoo Documentation](https://www.promptfoo.dev/docs/intro/) — 配置化回归与安全测试；本地规则先行，模型裁判按需运行。
- [CS329Z: Evaluation Task Assignment](https://github.com/cs329z/assignment2-evals) — 公开评测任务构建练习，配合自建 benchmark。
- [CS336 Lecture 12: Evaluation](https://github.com/stanford-cs336/lectures/blob/main/lecture_12.py) — 区分模型与系统测量、污染、真实任务效度与选型。
- [Terminal-Bench: Tasks and evaluation](https://www.tbench.ai/) — 真实终端任务、环境和结果验证的参考，按版本查看。 HW2 固定 2.1，官网当前 4.1；任务、harness 和结果按版本分别解释。
- [τ²-bench](https://github.com/sierra-research/tau2-bench) — 工具—Agent—用户三方模拟的客服类 Agent 基准，含 pass^k 可靠性指标。
- [pytest: assertions, fixtures and test execution](https://docs.pytest.org/en/stable/how-to/usage.html) — 完整官方测试指南；承担确定性契约与回归运行。
- [DeepEval: RAG evaluation quickstart](https://deepeval.com/docs/getting-started-rag) — 完整官方 RAG 与 pytest 式测评教程，作为 Ragas/runner 组合的备选。
- [Ragas: Context Precision and ID-based metrics](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/context_precision/) — 比较排序敏感与 ID 口径，给出字段和当前 API 示例。
- [Ragas: Faithfulness and metric API](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/) — claim 支持度、现代 collections API、限制与旧 API 迁移。
- [promptfoo: CI/CD evaluation](https://www.promptfoo.dev/docs/integrations/ci-cd/) — 完整配置/CI 入门，配合 Python provider 和断言操作。
- [Langfuse: evaluation and experiments](https://langfuse.com/docs/evaluation/overview) — 将线上 trace、标注、dataset 与离线实验连接起来；可自托管。
- [Inspect: Eval Sets](https://inspect.aisi.org.uk/eval-sets.html) — 任务组、日志、重试与恢复的官方实作资料。
- [Evidently Documentation](https://docs.evidentlyai.com/) — 数据漂移、预测漂移与模型质量监控，也覆盖 LLM 评测。
