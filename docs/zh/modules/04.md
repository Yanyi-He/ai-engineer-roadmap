## 04.1 Tokenizer、语料与训练目标

`core` · 实现：独立完成小型实现并验证行为

先修：[01.1 Python 语言与数据模型](../modules/01.md#unit-01-1), [03.2 概率统计与实验判断](../modules/03.md#unit-03-2)

### 知识框架

- BPE/WordPiece/Unigram、词表与 special tokens
- Unicode、多语言、padding/truncation 和 attention mask
- chat template、role delimiter 和终止 token
- next-token prediction、交叉熵与 perplexity
- 训练语料清洗、去重、污染与数据配比
- 从字节/Unicode 到 BPE 训练与 encode/decode 的最小练习；特殊 token 与多语言边界

### 资源与阅读范围

[Hugging Face LLM Course](https://huggingface.co/learn/llm-course/en/chapter1/1) — 公开课程正文，覆盖 tokenizer、数据、Transformers 与训练。

Tokenizer、文本预处理和因果语言建模章节。

### 动手任务

对同一段中英文比较 token 长度并检查 chat template。

### 自测题

1. 解释 BPE 的训练和编码过程；为什么同一段中文在不同模型中的 token 数差异很大？
2. 微调后模型不停止生成，或输出里出现奇怪的角色标记，你会如何检查 chat template 和特殊 token？
3. 解释困惑度与交叉熵的关系，以及为什么不同 tokenizer 的模型之间不能直接比较困惑度。

### 知识框架

### 资源与阅读范围

### 动手任务

实现最小 causal attention 并逐层标注张量维度。

### 自测题

1. 按顺序写出一个 decoder 层中张量形状的变化：embedding、QKV 投影、多头拆分、注意力、FFN 和输出 logits。
2. 为什么注意力分数要除以√d_k？去掉缩放或因果掩码写错，分别会出现什么现象？
3. 比较 pre-norm 与 post-norm，以及 SwiGLU 与 ReLU FFN 在参数量和效果上的取舍。

## 04.3 位置、注意力变体与模型架构

`advanced` · 解释：讲清机制、边界与选择依据

先修：[04.2 Transformer 完整计算链](../modules/04.md#unit-04-2)

### 知识框架

- 绝对/相对位置、RoPE 与长上下文扩展
- MHA/MQA/GQA、KV 数量与计算/内存取舍
- 稠密模型、MoE、router 与专家负载
- 线性/混合 attention、SSM 的基本动机
- decoder-only、encoder 与 encoder-decoder 适用任务
- MLA、滑动窗口/稀疏注意力、多 token 预测与 MoE 负载均衡（含无辅助损失方案）

### 资源与阅读范围

[Stanford CS336 Spring 2025: Language Modeling from Scratch](https://stanford-cs336.github.io/spring2025/) — 已有公开完整一季材料；AIE 选读模型、数据与效率，不要求做完预训练。

Architecture 与 attention 相关讲义；配合实现阅读。

### 动手任务

对两类模型画架构差异图并估算 KV 内存。

### 自测题

1. 解释 RoPE 如何编码相对位置，以及长度外推方法（如 NTK、YaRN 缩放）要解决什么问题。
2. 比较 MHA、MQA、GQA 和 MLA 对 KV cache 大小和推理吞吐的影响，并各举一个采用它的模型。
3. MoE 模型总参数很多但每个 token 的计算量不大。解释路由、专家负载均衡（含无辅助损失方案），以及部署时的显存与通信代价。

### 资源与阅读范围

3. 推理模型（长思维链、RLVR 训练）在哪些任务上明显优于普通模型，哪些任务上不值得？如何控制它的推理预算？

## 04.7 视觉编码器与对比学习

`core` · 解释：讲清机制、边界与选择依据

先修：[04.2 Transformer 完整计算链](../modules/04.md#unit-04-2)

### 知识框架

- ViT：patch 切分、位置编码与图像 token 数量
- CLIP/SigLIP 对比学习目标、温度与零样本分类
- 视觉编码器→projector/connector→LLM 的 VLM 结构与训练阶段
- 动态分辨率、图像切块、视频帧采样与显存/延迟
- 对比学习与文本 embedding、多模态检索的关系

### 资源与阅读范围

[Hugging Face: Vision Language Models Explained](https://huggingface.co/blog/vlms) — VLM 组成、训练方式、评测与开源模型选择的入门长文。

全文：VLM 组成、训练与评测；对比学习目标读 CLIP 论文方法部分。

### 动手任务

用一个开源 CLIP 类模型做零样本分类与图文检索，比较分辨率和提示词对结果的影响。

### 自测题

1. 解释 ViT 如何把图像切成 patch 并转成 token；一张高分辨率图片会占用多少视觉 token，怎么估算？
2. 解释 CLIP 的对比学习目标和温度参数，以及它如何实现零样本分类。
3. 描述典型 VLM 的结构（视觉编码器→projector→LLM）和训练阶段；为什么文本 embedding 模型也常用对比学习训练？
