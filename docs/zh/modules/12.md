## 12.3 LoRA、QLoRA 与参数高效微调

`advanced` · 实现：独立完成小型实现并验证行为

先修：[12.2 SFT 与训练正确性](../modules/12.md#unit-12-2)

### 知识框架

- 低秩更新、rank/alpha/dropout 和 target module
- 全量微调、LoRA、QLoRA、prefix/prompt tuning
- 量化 base、可训练 adapter 与优化器状态
- 训练内存、性能、合并和精度验证
- 多 adapter 管理、版本和回滚
- 实用微调栈：Unsloth、LlamaFactory、ms-swift（ModelScope）、torchtune；领域继续预训练

### 资源与阅读范围

LoRA、量化训练、target modules、保存/加载/合并。

### 动手任务

比较未微调、提示基线和 LoRA，记录质量与资源。

### 自测题

1. 解释 LoRA 的低秩更新原理，rank 和 alpha 如何影响效果；计算一个 4096×4096 线性层在 rank=16 时的可训练参数量。
2. QLoRA 训练后把权重合并再量化部署，效果明显下降，可能是什么原因？
3. 比较全量微调、LoRA 和 QLoRA 在显存、效果和部署（多 adapter 切换）上的取舍，并说明什么时候考虑继续预训练。

## 12.6 RLHF、PPO、GRPO 与可验证奖励

先修：[12.2 SFT 与训练正确性](../modules/12.md#unit-12-2), [03.2 概率统计与实验判断](../modules/03.md#unit-03-2), [03.4 神经网络与优化过程](../modules/03.md#unit-03-4)

- GRPO 奖励归一化、token/序列 loss reduction、长度偏差与零方差组
- on-policy/off-policy、重要性比率、clipping 与采样策略版本一致性

### 资源与阅读范围

[RLHF Book (Nathan Lambert)](https://rlhfbook.com/) — 免费在线 RLHF 教材：偏好数据、奖励模型、DPO 等直接对齐算法、PPO/GRPO 与可验证奖励，概念与公式连贯。

### 自测题

3. 解释 GRPO 中的零方差组、长度偏差和 token 级与序列级 loss 归约问题，以及 on-policy 与 off-policy 的区别。
