# CS329Z / CS336 课程对照

Stanford CS329Z 和 CS336 的内容分别落在本路线哪些单元、用哪个实验来练，以及 CS336 里哪些部分和应用 AIE 有关。课程材料核对于 2026-11-20。

## 要点

两门课涉及的主要技术在知识树里都有对应单元。本路线着重练的是：不用框架实现核心机制、数据策展、评测环境和评分器的验证、从模型评测走到业务选型、资源核算，以及基础知识在项目里的学习顺序。每一项都有对应的实验，少数方向放在专项。

## CS329Z：怎样落实课程设计

[课程主页](https://cs329z.stanford.edu/)与[教学设计](https://cs329z.stanford.edu/logistics.html)给出系统构建、评测和长期项目的安排。本路线采用“独立机制→框架迁移→固定 Agent 评测→产品交付”的顺序：

1. L01 建立模型接口，L13 实现自己的执行循环与协议，L02 补检索机制；随后迁移到 LangGraph 或 DSPy 等抽象。
2. L14 固定 Agent 与任务环境，先确认任务可解、评分器可靠，再比较独立试次；修复 Agent、环境或评分器时分别记录。
3. L15 把真实失败转成有血缘的数据；提示、模型与数据优化使用独立测试。
4. 项目有 proposal、基线、中期 demo/review 和最终复现；学习者解释实现与取舍，接受一项未见变更。

## 先修与学习路径

先修精确到单元，四条[路线](dependency-order.md)会自动展开先修：

- 主线：模型 API → 评测基线 → 检索与 RAG → 不用框架的 Agent 循环 → 工具、状态与权限 → 上线与运营；模型原理并行学。
- 企业知识：在主线上加深检索、结构化数据、权限和知识库运维。
- 本地推理与模型适配：小模型 → 资源核算 → 推理服务与压测 → 数据策展 → LoRA 与训练验证。
- Agent 平台：在主线上加深编排框架、工具目录、沙箱、记忆和多 Agent 协作；强化学习可选。

SFT、GPU 推理服务和复杂的多 Agent 实现按岗位选学；主线只需要模型 API 和通用后端。
