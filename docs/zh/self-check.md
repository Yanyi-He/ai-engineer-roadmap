# 自测题清单

[知识树](knowledge-tree.md) · [学习顺序](dependency-order.md) · [入门诊断](entry-diagnostic.md) · [能力评审](assessment.md)

每个单元3道面试式自测题，共378道。三道题大致对应：讲清机制、诊断问题、设计或实现。题目不附标准答案，答好所需的要点在对应单元的知识框架和主读资源里。

用法：

- 不看资料，口头或在纸上作答，每题2–3分钟。
- 答不出来：回到该单元的主读资源和知识框架。
- 能讲清原理，却举不出自己的代码、实验或线上案例：完成该单元的实践产物。
- 先覆盖core单元（267道）；advanced和elective按目标岗位选做。
- Fork本仓库后，把`[ ]`改成`[x]`记录进度。
