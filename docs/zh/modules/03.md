## 03.1 线性代数与数值基础

`core` · 实现：独立完成小型实现并验证行为

先修：[01.1 Python 语言与数据模型](../modules/01.md#unit-01-1)

### 知识框架

- NumPy 向量/矩阵/张量、维度、广播与矩阵乘法
- 点积、范数、余弦、正交和相似度
- 导数、链式法则、梯度与 Jacobian 概念
- 浮点数、溢出、log-sum-exp 和数值稳定
- 参数规模、激活与计算量的数量级估算

### 资源与阅读范围

[Dive into Deep Learning](https://d2l.ai/) — 完整交互教材；选择线性模型、优化、注意力和 Transformer。

Preliminaries：Linear Algebra、Calculus 和 Automatic Differentiation。

### 动手任务

手算并用张量验证 softmax、余弦和一次梯度更新。

### 自测题

1. 解释余弦相似度与点积的关系；向量归一化之后两者有什么区别？
2. softmax 计算出现 NaN 或 inf，可能的原因是什么？写出数值稳定的 softmax 实现。
3. 估算形状为(batch, seq, d_model)的张量与(d_model, 4·d_model)矩阵相乘的 FLOPs 和输出显存。

## 03.2 概率统计与实验判断

`core` · 诊断：定位失败、设计对照并修正

先修：[03.1 线性代数与数值基础](../modules/03.md#unit-03-1)

### 知识框架

- 条件概率、Bayes、期望、方差与常见分布
- 抽样单位、相关性、偏差/方差和置信区间
- 假设检验、效应大小、功效和多重比较概览
- 配对实验、cluster bootstrap、时间与群组切分
- 校准、覆盖率、选择偏差与相关/因果
- 熵、交叉熵、KL 散度与互信息；MLE/MAP 与常见损失函数的关系

### 资源与阅读范围

[OpenIntro Statistics](https://www.openintro.org/book/os/) — 免费开放统计教材：抽样、置信区间、假设检验、功效与配对数据，覆盖实验判断所需的统计基础。

概率与分布、推断基础、数值数据推断（含配对数据）与功效；bootstrap 实现对照 SciPy 文档；信息论读 D2L 附录 Information Theory。

### 动手任务

比较同题两系统，报告配对差异与不确定性。

### 自测题

1. 解释交叉熵、KL 散度和最大似然估计的关系；为什么分类模型用交叉熵作为损失？
2. 新 Prompt 在 50 条测试上把准确率从 70% 提到 76%，你如何判断这是真实提升（配对比较、置信区间、样本量）？
3. 同一用户的多轮对话同时进了训练集和测试集，会造成什么偏差？应该如何划分数据并计算置信区间？

## 03.6 传统 ML 上线与 MLOps

`advanced` · 实现：独立完成小型实现并验证行为

先修：[03.3 机器学习任务与泛化](../modules/03.md#unit-03-3), [02.6 云、容器与发布基础](../modules/02.md#unit-02-6)

### 知识框架

- 特征管道与特征存储：离线和在线特征一致、时间点正确的训练数据（Feast 等）
- 实验跟踪与模型注册：参数、指标、数据版本和模型版本（MLflow）
- 批量打分与在线服务：定时批处理、实时 API 和托管服务（SageMaker、Databricks Model Serving 等）
- 监控：数据漂移、预测漂移、标签延迟时的效果监控与重训触发（Evidently 等）
- ML 的 CI/CD：数据校验、训练流水线、模型对比门槛与回滚
- 模型治理：模型卡、审批记录与受监管行业的模型风险管理

### 资源与阅读范围

[DataTalksClub MLOps Zoomcamp](https://github.com/DataTalksClub/mlops-zoomcamp) — 免费 MLOps 课程：实验跟踪、编排、批量/在线/流式部署、监控与最佳实践。

MLOps Zoomcamp 的实验跟踪（MLflow）、编排、部署（批量/在线/流式）、监控和最佳实践各模块；特征存储与漂移监控按需查 Feast、Evidently 文档。

### 动手任务

把一个表格分类模型（例如工单分流）从 notebook 带到生产：特征管道、MLflow 注册、批量和在线打分、漂移报告与重训触发，并写一份模型卡。

### 自测题

1. 训练时的特征和线上打分时的特征不一致（training-serving skew）会造成什么问题？特征存储怎样缓解？
2. 模型上线三个月后效果下降，但标签要一个月后才拿到。你如何用数据漂移和预测漂移提前发现问题，并决定是否重训？
3. 设计一个模型发布流程：实验跟踪、模型注册、离线对比门槛、灰度上线和回滚，并说明需要保留哪些审计记录。
