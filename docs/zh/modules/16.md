## 16.1 强化学习与动态环境基础

`elective` · 解释：讲清机制、边界与选择依据

先修：[03.3 机器学习任务与泛化](../modules/03.md#unit-03-3), [03.4 神经网络与优化过程](../modules/03.md#unit-03-4)

### 知识框架

- 状态、动作、转移、奖励和 partial observation
- Bellman、value-based、policy-based 与 actor-critic
- online/offline、model-free/model-based 和 imitation
- 探索、credit assignment、分布迁移和安全
- 仿真指标、任务成功与真实环境评估

### 资源与阅读范围

[Hugging Face Deep RL Course](https://huggingface.co/learn/deep-rl-course/unit0/introduction) — 完整免费 RL 理论与实作课程，作为选修先修。

MDP、value、policy、策略梯度与 actor-critic。

### 动手任务

对一个仿真任务画 MDP 并复现简单策略。

### 自测题

1. 解释 Bellman 方程、价值函数与策略的关系，以及 actor-critic 方法的基本结构。
2. 智能体在仿真中表现很好，换一个随机种子或环境参数就失败，可能是什么原因？
3. 比较在线 RL、离线 RL 和模仿学习的数据需求与风险，并各举一个适用场景。

<a id="unit-16-2"></a>

## 16.2 世界模型与规划

`elective` · 解释：讲清机制、边界与选择依据

先修：[16.1 强化学习与动态环境基础](../modules/16.md#unit-16-1), [04.2 Transformer 完整计算链](../modules/04.md#unit-04-2)

### 知识框架

- 潜在状态、动力学预测、观测模型和 action conditioning
- 视频生成、可交互模拟与决策模型的不同任务
- 模型学习→想象 rollout→规划/策略改进
- 不确定性、长期误差、分布外行为和可控性
- Dreamer/JEPA 等方向的研究问题与应用边界

### 资源与阅读范围

[DreamerV3](https://github.com/danijar/dreamerv3) — 作者的世界模型实现，阅读研究问题与实验结构。

作者代码、论文与训练/评测流程。

### 动手任务

解释一个 world-model 方法的数据流与评测目标。

### 自测题

1. 什么是世界模型？解释 Dreamer“学习模型→想象 rollout→改进策略”的流程。
2. 用世界模型做长时域规划时误差不断累积，原因是什么？有哪些缓解方法？
3. 比较视频生成模型与用于决策的世界模型在目标和评估上的区别，并说明 JEPA 的思路。

## 16.3 机器人软件与仿真

`elective` · 实现：独立完成小型实现并验证行为

先修：[01.6 开发环境、Linux 与协作](../modules/01.md#unit-01-6), [03.1 线性代数与数值基础](../modules/03.md#unit-03-1)

### 知识框架

- 机器人坐标、运动学、传感器和控制闭环概览
- ROS2 节点、topic/service/action 和数据记录
- MuJoCo/Isaac Lab、环境 reset 和任务定义
- domain randomization、sim-to-real 与安全限制
- 可重复仿真、数据版本和任务成功指标

### 资源与阅读范围

[MuJoCo Documentation](https://mujoco.readthedocs.io/en/stable/overview.html) — 官方物理仿真、模型与 Python 接口。

模型、simulation、控制与 Python 接口基础。

### 动手任务

运行一项仿真任务，记录观测、动作与成功条件。

### 自测题

1. 解释 ROS2 中节点、话题、服务和动作的区别，以及各自适合什么类型的通信。
2. 策略在仿真中成功、在真机上失败，从 sim-to-real 角度分析原因，并说明域随机化的作用。
3. 在 MuJoCo 或 Isaac Lab 中定义一个抓取任务：观察、动作、奖励、重置和成功判定。

## 16.4 模仿学习、VLA 与机器人数据

`elective` · 解释：讲清机制、边界与选择依据

先修：[16.3 机器人软件与仿真](../modules/16.md#unit-16-3), [03.5 PyTorch 训练工程](../modules/03.md#unit-03-5), [05.6 视觉、文档与多模态输入](../modules/05.md#unit-05-6)

### 知识框架

- teleoperation、demonstration 和多模态动作数据
- behavior cloning、ACT、diffusion policy 与 action chunking
- VLM 到 VLA、语言条件策略与动作表示
- 数据质量、task/robot 分布、泛化与失败恢复
- 离线评估、仿真与硬件试验的证据差别

### 资源与阅读范围

[LeRobot Documentation](https://huggingface.co/docs/lerobot/index) — 公开机器人数据、策略与训练评测指南。

数据集、策略训练、评估与硬件适配指南。

### 动手任务

读一个 LeRobot 数据集并说明训练与部署接口。

### 自测题

1. 解释行为克隆的复合误差问题，以及 ACT 的动作分块（action chunking）如何缓解它。
2. VLA 模型如何从 VLM 扩展而来？语言指令、视觉输入和动作输出是如何连接的？
3. 设计机器人数据采集方案：遥操作、多任务覆盖和失败恢复示范，以及如何评估泛化能力。
