# Task card / 任务卡

- User and workflow / 用户与流程:
- Concrete input and expected outcome / 具体输入与期望结果:
- Manual or rule baseline / 人工或规则基线:
- Why use a model; why use an agent / 为什么需要模型与Agent:
- Non-goals and domain limits / 非目标与领域边界:
- Error classes and business loss / 错误类别与损失:
- Success, quality, latency and cost constraints / 成功、质量、延迟与费用约束:
- Data sources, license and labeling / 数据、许可与标注:
- Principal, permissions and approval boundary / 身份、权限与审批:
- Available evidence versus assumptions / 已有证据与假设:
- First falsifiable hypothesis and stop condition / 首个可证伪假设与停止条件:

Use concrete examples. Label hypothetical users or synthetic tasks explicitly. / 用例子说明，明确标记假设用户与合成任务。
