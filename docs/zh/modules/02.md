## 02.1 HTTP、API 与流式交互

### 知识框架

- HTTP 语义、状态码、REST、分页、OpenAPI 和 API 版本
- DNS/TCP/TLS、代理、连接复用与连接超时
- SSE/WebSocket、流中断、心跳和客户端重连
- request ID、幂等键、错误分类与 deadline
- 上传/下载、对象存储引用和大文件限制

### 资源与阅读范围

[FastAPI Tutorial](https://fastapi.tiangolo.com/tutorial/) — 类型、依赖注入、异步、认证和测试的完整维护者教程。

请求、依赖、异常、认证、测试与 StreamingResponse。

### 动手任务

实现异步任务 API 与 SSE 事件回放。

### 自测题

1. 比较 SSE 和 WebSocket 用于 LLM 流式输出时的适用场景，以及它们在代理、超时和断线重连上的差异。
2. 用户反馈流式回答经常在 30 秒左右中断，你会检查哪些环节（反向代理缓冲、超时、心跳、负载均衡）？
3. 设计一个“上传文档并异步解析”的 API：请求、状态查询、幂等键、错误码和大文件限制分别怎么定？

## 02.3 事务、幂等与一致性

`core` · 诊断：定位失败、设计对照并修正

先修：[02.2 SQL、数据建模与索引](../modules/02.md#unit-02-2)

### 知识框架

- 隔离级别、丢失更新、乐观锁与悲观锁
- 唯一约束、CAS、请求 payload 与幂等键绑定
- at-least-once、重复消息、顺序与去重
- transactional outbox、补偿和外部提交结果未知
- 事件时间、处理时间、版本与审计

### 资源与阅读范围

[AWS Builders Library: Idempotent APIs](https://aws.amazon.com/builders-library/making-retries-safe-with-idempotent-APIs/) — 完整免费工程文章，理解重复请求、重试与副作用。

全文；配合 PostgreSQL 并发控制与版本检查。

### 动手任务

复现外部操作成功但本地状态未提交的崩溃窗口。

### 自测题

1. 解释丢失更新问题，以及乐观锁、悲观锁和数据库约束各自如何防止它。
2. Agent 调用“创建退款”工具后超时，不知道外部系统是否已执行，你如何设计幂等键和对账，避免重复退款？
3. 说明 outbox 模式如何保证“写数据库”和“发消息”一致，并写出至少一次投递下消费者的去重逻辑。

## 02.4 缓存、队列与后台任务

`core` · 诊断：定位失败、设计对照并修正

先修：[01.3 异步、并发与取消](../modules/01.md#unit-01-3), [02.3 事务、幂等与一致性](../modules/02.md#unit-02-3)

### 知识框架

- Redis 缓存模式、TTL、失效、击穿与一致性
- 消息队列、ack、重试、DLQ 和延迟任务
- worker 池、lease、心跳与 fencing token
- 限流、熔断、隔离、背压与公平调度
- 任务状态机、进度、取消与可重放事件

### 资源与阅读范围

[System Design Primer](https://github.com/donnemartin/system-design-primer) — 高星免费系统设计教材：缓存模式、异步队列、背压、一致性与可用性取舍，也是系统设计面试的公共底稿。

Cache、Asynchronism、Back pressure 与可用性/一致性章节；重试与幂等对照 AWS Builders Library。

### 动手任务

两个 worker 竞争同一任务，验证旧 worker 无法覆盖新结果。

### 自测题

1. 解释缓存击穿、雪崩和穿透的区别，以及各自的缓解手段。
2. 后台文档解析任务偶尔被执行两次，索引里出现重复片段，你如何从 ack、租约和幂等写入三方面排查？
3. 为长时间运行的 LLM 批处理任务设计 worker：重试、死信、进度上报、取消，以及避免单个租户占满资源的公平调度。

- 企业接入：SSO/权限、事务、审计与既有微服务治理
- C#/.NET、Go 生态的同类能力与选型

### 资源与阅读范围

3. 在已有 SSO 和权限体系的企业系统中接入 RAG 助手，权限过滤、事务和审计应该放在哪一层？
